Secure moderation

Kick, ban, timeout, warn and purge with Discord's role hierarchy enforced server-side on every action, plus an append-only case history.

AutoMod that explains itself

Spam, invites, links, blocked words, mentions, lines and caps. Every enforcement is mirrored to your moderation log with the exact trigger.

Tickets with transcripts

Button-driven private channels, claimable by staff, closed with a plain-text transcript archived to the channel you choose.

Leveling and rewards

XP per message with cooldowns, a quadratic curve, level reward roles and reputation — all tunable per server.

Giveaways

Live countdowns, one entry per member enforced in the database, weighted draws and rerolls that never pick a previous winner.

Built for self-hosting

Parameterised SQL, per-guild isolation, hardened HTTP headers and a dashboard that refuses to start without an authentication provider.
